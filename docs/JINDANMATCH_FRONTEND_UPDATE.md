# 진단매치 FrontEnd 기능 개선

## 작업 브랜치
- feature/jang-create-project

## 작업 목적
의뢰인의 기업진단 의뢰 과정을 간편하고 직관적으로 개선하고,
회원/비회원 의뢰 및 업종별 진단 입력 흐름을 정리하였습니다.

## 주요 개선 내용

### 1. 기업진단 의뢰 화면
- 현재 사업 상태 선택
- 진단 분야 선택
- 업종별 Progressive 입력 방식 적용
- 상위 선택 변경 시 하위 입력값 초기화

### 2. 업종별 입력 플로우
- 건설업
- 전기공사업
- 정보통신공사업
- 소방시설공사업
- 산림사업법인
- 의약품
- 국가유산수리업
- 기타

### 3. 재무정보
- 자본금
- 현재 총자산
- 창업예정 시 예정 자본금

### 4. 의뢰 마감
- 오늘 / 내일 / 모레
- 오전/오후, 시, 분 선택
- 현재 시각 기준 최소 20분 이후부터 최대 48시간 이내 선택

### 5. 의뢰 내용 확인
- 사업 정보
- 진단 정보
- 재무 정보
- 의뢰 마감 정보
- 항목별 수정 기능
- 최종 의뢰 등록 확인 모달

### 6. 비회원 의뢰
- 회원가입 없이 휴대폰 번호 기반 간편 의뢰
- 향후 카카오톡 인증번호 연동 예정
- 휴대폰 인증 후 내 의뢰 진행상태 및 전문가 제안 조회 구조

### 7. 의뢰 완료 화면
- 의뢰 등록 완료 안내
- 비회원 휴대폰 번호 기반 조회 방식 반영
- 내 의뢰 확인 흐름 개선

### 8. 상단 메뉴 개선
- 견적 요청 메뉴 단순화
- 기업진단 의뢰하기
- 내 의뢰 확인하기

## 향후 연동 예정
- 카카오톡 휴대폰 인증 및 알림
- 전문가 제안/입찰 현황
- PG 결제
- 전문가 자동 정산
- 전자세금계산서
- 관리자 결제/정산/회원등급 관리

## 로컬 개발 환경
- FrontEnd: Vite
- FrontEnd Port: 5173
- Backend Local Port: 8081

## 실행

```bash
npm.cmd run dev
```
